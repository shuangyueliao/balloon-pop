# Balloon Pop

Free single-file HTML5 arcade game. Pop rising balloons before they float
away: big 1pt, small 3pt, gold 5pt. Chain balls blast nearby balloons,
clock balls add +3s, dodge spike balls and balloon-stealing bees.
60-second rounds with combo multipliers up to x3. One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/balloon-pop/

- Mouse / touch (tap or hold & swipe to pop), procedural WebAudio sounds
- Glow balloons, confetti pops, swaying strings and sky scene — all canvas-drawn, no dependencies
- Best score / best combo saved locally, mute toggle
